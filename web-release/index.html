ANDROID INSTALL

安卓安装与权限说明

无需危险运行时权限

APK 仅声明联网、振动和应用内部保护权限，不申请相机、麦克风、定位、通讯录、电话、短信、照片/文件、通知或身体传感器权限。安装后可直接进行安全自查、方案复核、训练记录和数据导出。

  1. 下载 APK 后，在通知栏、浏览器“下载内容”或文件管理器中点开。
  2. 若系统拦截，进入提示里的“设置”，只为当前浏览器或文件管理器开启“允许安装未知应用/允许来自此来源”。
  3. 返回安装页点“安装”；完成后从桌面或应用列表打开“健康守护者”。建议安装完成后关闭刚才的来源授权。
小米 / Redmi（HyperOS、MIUI）

设置 → 更多设置 → 隐私保护/隐私 → 特殊应用权限 → 安装未知应用 → 选择本次下载所用的浏览器或文件管理器 → 允许。也可在设置顶部搜索“安装未知应用”。

华为（HarmonyOS、EMUI）

设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 选择本次下载来源 → 允许安装应用。若菜单名称不同，直接在设置中搜索“外部来源应用”。

荣耀（MagicOS）

设置中搜索“外部来源应用下载”并开启；再进入“安装外部来源应用”，选择本次使用的浏览器或文件管理器，开启“允许安装应用”。

OPPO / 一加 / realme（ColorOS、realme UI）

设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选择本次下载来源 → 允许。旧系统可在“设置 → 安全/更多安全设置 → 未知来源安装”中找到。

vivo / iQOO（OriginOS）

设置 → 应用与权限 → 权限管理 → 权限 → 安装未知应用 → 选择本次下载来源 → 开启“允许安装未知应用”。也可在设置中搜索该名称。

三星（One UI）及其他 Android

三星：设置 → 安全和隐私 → 安装未知应用；如开关不可用，先在同页暂时关闭“自动拦截器”，安装后再重新开启。其他品牌可在设置中搜索“安装未知应用”。

仍无法安装：确认系统为 Android 7.0 或更高版本、预留至少 300MB 空间，并核对页面显示的 SHA256。单位或家长管控设备可能由管理员禁止侧载，此类系统策略不能由应用绕过。
