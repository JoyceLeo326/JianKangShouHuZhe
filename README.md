# 健康守护者

健康守护者是一个个人作品演示，用于展示手部康复场景下的记录管理、趋势汇总、提醒闭环、设备状态演示和可选 AI 记录解读。以下患者、训练与设备数据均为虚构演示数据，不代表真实用户、真实医疗结论或运营成果。

## 能力与医疗边界

- “AI 康复助手”只整理用户录入的记录，提供需要专业人员复核的训练建议草案；不提供诊断，不能替代医生或康复师，也不用于急救。
- 本地演示模式使用确定性规则，不冒充模型输出。用户可自行配置第三方 AI 服务，数据会按用户选择直接发送给对应服务商或用户配置的代理。
- 报告可在 Web 端下载为 Markdown；原生端会展示已生成的 Markdown 文本，便于用户另行保存或复制。

## 数据与隐私边界

- 默认工作区在 Web 端通过 `AsyncStorage` 的浏览器适配保存到 `localStorage`，原生端使用 `AsyncStorage`；持久化存储不可用时只保存在当前运行内存，关闭或刷新后可能丢失。
- 只有用户主动选择并成功登录可选服务端账号时，工作区数据才会提交到项目自带服务端。演示部署不承诺云端备份、医疗合规认证或持续可用性。
- API Key 仅保存在当前设备；调用第三方模型时会由当前设备或用户填写的代理发往所选服务商。
- 本地工作区可在“我的 → 注销账号与删除数据”清除；服务端账号使用同一入口请求删除服务端记录。

## 本地运行与验证

```bash
npm ci
npm test
npm run check:syntax
npm run build:web:demo
```

`npm test` 同时覆盖 API/保存/删除闭环和产品真实性、医疗边界、报告导出验收。
