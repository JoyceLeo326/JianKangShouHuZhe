# 康复旅程叙事资产清单

生成静态镜像：

```powershell
npm run build:static-mirror
```

输出目录：`release/github-pages-deploy`

24 幅独立 WebP 叙事画面均由界面中的康复旅程画廊引用。画廊一次只渲染当前一幕，并随状态输入、风险评估、候选选择、人工确认、完成反馈、下次复盘和交接导出切换。
